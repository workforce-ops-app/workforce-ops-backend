# Project Features: Backend

**In short:** one page per feature describing its rules, permissions, states, endpoints, data, and audit events. The matching page in the frontend repository describes the screens.

New pages start from the [feature template](https://github.com/workforce-ops-app/.github/blob/main/docs/templates/feature.md). A feature's page is written before its code, at the start of its tier ([decision 0023](https://github.com/workforce-ops-app/.github/blob/main/docs/decisions/0023-feature-tiers-and-audit-schedule.md)).
